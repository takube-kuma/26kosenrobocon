          岐阜A「前途羊々」の特徴

          全国大会はベスト8・本田技研工業特別賞。1回戦で秋田Bに220-0、2回戦で米子Aに200-100で逆転勝ちし、準々決勝で優勝した大阪公大Aに420-425の5点差で敗れました。3試合ともスーパー雑巾を旗に掛け、準々決勝の420点はチームの今年の最高点です。

          東海北陸地区から推薦で7年ぶりの全国出場。学校のマスコット「ラムちゃん」が乗ったロボットです。いちばんの特徴は、雑巾をロボット自身がおしぼりのように巻き、時速約90kmで回るベルト（ローラー）に突っ込んで水平に連射し、机を狙うこと（1回の装填で10発）。スーパー雑巾は別の投石機で旗に掛ける、2本立ての構成です。NHKの番組では「スーパー雑巾を旗に掛ける操縦技術と、高速で射出される雑巾による高得点」が推薦の理由として紹介されました。

          1. 椅子の下に重ねた雑巾（平置きの束）
          2. 下部の巻き取り・ローラー部（黄色い光の帯のあたり）
          3. 塔の中の斜めの板（雑巾の通り道と思われる）
          4. 塔の上の黒い受け部（スーパー雑巾の投石機と思われる部分）
          5. 移動バケツ（X字リフトの塔の上）
          6. 赤いタンク（エア用と思われる）

          写真はエキシビションの配信映像から切り出したもの。番号の位置は映像からの読み取りで、チームの公式な解説ではありません。動いている様子はで見られます。

          機構のまとめ

          機構内容
          雑巾の巻き機構「丸めて折った雑巾は投げやすく入りやすい」と分かり、工場でおしぼりを巻く機械を参考に、雑巾を巻く機構を作った（エキシビション後の選手インタビュー）。実況も「ロボットの下で機械が丸めてくれている」。
          ローラー連射（机）おしぼり状にした雑巾をローラーで水平に飛ばす。実況は「相当速いスピードでマシンガンのように打ち出す」。予選A-1では机の口に何度も当たり、エキシビションで入った。
          NHKの番組で分かったことベルトは時速約90kmで回り、そこに雑巾を突っ込んで机の引き出しを狙う。飛び方にはばらつきがあり、それを操縦者の腕で調整する（選手談）。1回の装填で10発打てる連射の速さが売り。本番前日のテストランでは机も旗も成功していた。
          投石機（スーパー雑巾）旗はオーバースロー。雑巾を入れる黒い受け部の形とサイズを試行錯誤し、雑巾を受け部から「すっと垂れるくらい」に置くのが研究の成果（実況）。予選A-1とエキシビションで旗に掛けた。
          移動バケツの塔X字（パンタグラフ）リフトの塔の上に移動バケツ。予選A-4では実況が「この対策のために高く上げている」と解説。
          課題予選A-4は机用の機構のモーターが動かず、0-5で敗戦（選手談）。選手は「本来は400点（スーパー雑巾2枚）を掛ける実力」と話し、全国の目標は過去最高の440点。

          大会前の見どころは、全国でどうだったか

          1. 得点の中心はスーパー雑巾の旗だった

            3試合でスーパー雑巾を計4枚旗に掛け（1回戦1枚・2回戦1枚・準々決勝2枚＝800点）、3試合の合計840点のうち95%を占めました。地区大会では2試合で1枚だった旗が、全国では毎試合決まっています。NHKの番組で推薦の理由とされた「スーパー雑巾を旗に掛ける操縦技術」がそのまま勝ち上がりの力になりました。

          2. 机の水平連射は20点ずつ

            ロボットが自分で雑巾を巻き、時速約90kmのローラーで机を狙う岐阜Aならではの機構は、1回戦と準々決勝で机に1枚ずつ（20点）。準々決勝では32枚中30枚を打ち切ったと選手が話しています。机の20点は、5点差で敗れた準々決勝で「もう1枚」が届けば勝敗が変わった得点源でした。

          3. 移動バケツ対策：1枚は入れられたが、かわして逆転

            2回戦では米子Aに開始直後に移動バケツへ1枚（100点）入れられましたが、その後は動き回って狙いをかわし、残り30秒でスーパー雑巾を旗に掛けて逆転。最後は旗の裏に隠れて守り切りました。大会前に挙げた「装填中に移動バケツを狙われないこと」は、2回戦の最大の山場になりました。

          4. 準々決勝は大阪公大Aのシールドに阻まれた

            先に机で20点を取りましたが、優勝した大阪公大Aの高い「広大シールド」が岐阜Aの前に張り出し、机や旗を狙いにくくなりました。大阪公大Aが旗に2枚掛けて225-20とした後、岐阜Aは最後にスーパー雑巾2枚を旗に掛けて420点まで追い上げましたが、大阪公大Aも終盤に旗へ掛けて425点としていて、5点届きませんでした。

          5. 目標の440点に迫った

            大会前の目標は旗2枚（400点）＋机。準々決勝の420点は、机1枚分（20点）で目標に届く点でした。地区大会は2試合で最高200点・2試合目は0点でしたが、全国は3試合とも得点し、0点の試合はありませんでした。

          出典：全国大会のYouTube配信（ロボコン公式チャンネル）の得点表示・実況・インタビュー、公式のトーナメント表。大会前の見どころは、東海北陸地区大会の配信とNHKの番組「高専ロボコン2026 地区大会」からまとめたものです。

                勝つためにはどうすればいい？

                8地区・150試合の結果から読み取れる「勝ち方」。数字は全地区の合計（上の地区ボタンでは変わりません）。勝率はその条件の試合で勝った割合です。

                1. まずは1点でも取る（予選はこれで勝てる）

                  0点だった試合の勝率は27%、1点でも取った試合は77%。得点で勝った108試合のうち29試合は10点以下での勝利で、5点バケツ1〜2個で決まる試合がとても多いです。0-0は審査員判定（全体の28%）になり運任せなので、どんな相手でも確実に入る5点バケツ用の1発を持つことが最優先です。

                2. 勝ち上がるには旗（100点）が必要

                  全得点の74%は旗から。旗に掛けた試合の勝率は85%で、全国大会に出た25チームのうち17チームが地区大会で旗に掛けています。決勝トーナメントでは平均得点が予選の約3倍（113点 vs 35点）になり、100点未満の得点だと勝率32%、100点以上なら77%。勝ち上がったチームの多くは100点を取れる武器を持っていました。

                3. スーパー雑巾（2分以降）は旗に掛ける準備をしておく

                  ゴールに入ったスーパー雑巾40枚のうち37枚が旗。1枚で200点になり、11試合はスーパー雑巾の点がそのまま勝敗を分けました（関東決勝230-220、四国決勝400-245、東海北陸の準決勝は福井Aが残り10秒で2枚掛けて5-20から405-20に逆転など）。2分の時点で旗を狙える位置にいて、すぐ装填できるように段取りしておくのが効きます。

                4. 止まっている相手の移動バケツを狙う、自分のバケツは守る

                  移動バケツに入ったのは全体で15枚・6チームだけですが、中国優勝の米子Aは9枚を決め、準決勝は移動バケツ3枚（300点）で旗のスーパー雑巾（200点）に勝ちました。狙われるのは装填などで止まっている時間。逆に守る側は、装填を早くする・相手の近くで止まらない・バケツを上げる、が有効です。バケツを上げて守るチームの勝率は61%（動かさないチームは49%）で、優勝8チーム中3チームがこの工夫をしていました（東海北陸のチームは映像で確認できていないので除く）。

                5. 旗が両方決まったら5点バケツの数で決まる

                  関東決勝は茨城Aと都立荒川Aがどちらもスーパー雑巾を旗に1枚ずつ掛け、5点バケツ6個 vs 4個の差で茨城Aが230-220で優勝。茨城Aは大会を通して5点バケツを24個入れていて、旗を狙いつつ合間に5点バケツを積み上げる手数の多さが最後の差になりました。

                6. 機構の傾向（参考）
